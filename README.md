# 📦 Warehouse Management System

A Windows Forms desktop app (C#) for managing warehouse inventory: products, stock in/out, suppliers, and reports.

## Features
- Product and category management
- Stock in/out tracking with low-stock alerts
- Suppliers and customers
- Reports

## Setup
1. Clone the repo and open the `.sln` in Visual Studio.
2. Restore the database from `Database/WarehouseDB.sql` in SQL Server.
3. Update the connection string in `App.config`.
4. Press **F5** to run.
